버스 자동예매

고속버스·시외버스 취소표를 자동으로 선점 · 결제는 공식 페이지에서

1 · 운영사 & 터미널

터미널 이름(목록) 또는 코드를 입력하세요.

로그인 없이 조회·선점됩니다. 목록에 없는 터미널은 코버스/티머니 사이트에서 노선을 고를 때 보이는 코드를 직접 입력하세요.

2 · 날짜 · 시각 · 인원

선점은 성인 1명 기준입니다. 간격은 자동선점 시작 전에 설정하세요(최소 5초, 기본 10초).

3 · 조회

4 · 자동 선점

특정 편을 노리려면 조회 결과에서 자동선점 대기를 누르세요. 앱을 내려도 백그라운드로 계속 시도하고, 자리가 잡히면 알림 후 공식 결제 페이지로 자동 이동합니다. 선점은 몇 분 내 만료되니 바로 결제하세요.

실행 중

결제(카드 입력)는 자동화하지 않습니다. 결제 후 뒤로가기로 앱에 돌아오세요.
과도한 반복 조회는 피합니다(간격 하한 5초). 개인 용도로만 사용하세요.
