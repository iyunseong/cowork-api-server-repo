# 버스 자동예매 — 고속버스(코버스) · 시외버스(티머니) 취소표 자동 선점

KTX·SRT 앱(`../mobile`)과 **별개로 설치되는 안드로이드 앱**입니다(패키지 `com.kskill.busmacro`).
로그인 없이 시간표를 조회하고, 매진 편을 감시하다 자리가 나면 **좌석을 임시 선점**한 뒤 알림을
보내고 **공식 결제 페이지로 자동 이동**합니다. 카드 결제는 직접 합니다.

k-skill의 `express-bus-booking`(KOBUS) / `intercity-bus-booking`(티머니) 스킬이 세션 검증한
HTTP 흐름을 JS로 포팅했고, 파서는 두 헬퍼의 파이썬 함수를 오라클로 대조 검증합니다(`test/`).

## 설치
GitHub Releases에서 `bus-auto-booking.apk`(태그 `bus-vX.Y.Z`)를 받아 설치합니다. KTX 앱과 같은
고정 서명 키를 쓰므로 이후 버전은 덮어쓰기 업데이트가 됩니다.

## 사용
1. 운영사(고속/시외) 선택 → 출발/도착 터미널 입력(목록 또는 코드)
2. 날짜·시각·자동선점 간격 설정 → **시간표 조회**
3. 자동 선점 방식 중 하나 선택
   - 조회 결과의 **자동선점 대기**(매진 편도 목록에 표시됨)
   - **출발시각 직접 지정**: 목록에 안 뜨는 매진 편도 시각만 넣으면 대기 가능
   - **시간대 지정**(예: 13:00~16:00): 그 사이 출발편 중 자리가 나는 가장 빠른 편을 선점
   - 시각 제한 없이 가장 빠른 빈자리
4. 자리가 잡히면 알림 → 결제 페이지 자동 이동 → **몇 분 내 결제** (미결제 시 선점 만료; 고속버스는 "선점 취소" 가능)

## 터미널 코드
공개 코드표가 없어 검증된 시드만 내장합니다(서울경부 010, 센트럴시티 021, 부산 700, 광주 500,
포항 828 / 동서울 0511601, 속초 2482701). 이름이 시드에 없으면 조회 시 사이트에서 자동으로 찾아보고
(고속버스: 노선 목록 ajax, 시외버스: 터미널 페이지·후보 엔드포인트를 훑어 7자리 코드↔이름 쌍 추출),
"터미널 목록 불러오기"로도 같은 조회를 할 수 있습니다. 어느 쪽이든 코드를 직접 입력할 수 있고,
찾은 코드를 알려주시면 시드에 추가합니다.

## 개발
```bash
cd mobile-bus && npm install
npm test          # 파서 대조(파이썬 stdlib만 필요) + mock 흐름
npm run build     # src -> www (공유 macro.js는 ../mobile/src에서 복사)
```
CI: `.github/workflows/android-bus.yml` — 커밋 메시지에 `[release-bus]`가 있으면 `VERSION`의 태그로 Release 발행.

## 주의
- 취소표 효용은 명절·성수기 인기노선에 집중됩니다(평시엔 증차로 매진이 드묾).
- 과도한 폴링 금지(간격 하한 5초). 개인 용도로만 사용하세요.
- 사이트 마크업이 바뀌면 파서 갱신이 필요할 수 있습니다. 결제 페이지 자동 이동(WebView 세션 공유)은 실기기에서 확인이 필요합니다.
